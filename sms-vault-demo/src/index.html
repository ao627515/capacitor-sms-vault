⚠️ Restriction Android 13+ (Sideload)

Si vous installez cette application via un APK direct (sideload), Android bloque l'accès aux permissions sensibles par défaut.

Procédure de déblocage :

  1. Faites un appui long sur l'icône de l'app sur votre écran d'accueil.
  2. Sélectionnez Infos sur l'appli (App info).
  3. Appuyez sur le menu **⋮** (trois points) en haut à droite.
  4. Sélectionnez Autoriser les paramètres restreints (Allow restricted settings) et validez.
  5. Allez maintenant dans le menu Autorisations / Permissions → SMS et passez sur Autoriser.

Ce paramètre se réinitialise à chaque réinstallation de l'APK de test.
